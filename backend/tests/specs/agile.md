# Планировщик спринтов

Продукт помогает командам планировать спринты и следить за прогрессом.

## Цели продукта

Нужно решить три задачи:
- собирать задачи в едином бэклоге
- оценивать трудоёмкость
- показывать скорость команды

**Роли пользователей**

Система должна поддерживать роли владельца и участника.

Модель доступа
--------------

Участник может менять только свои задачи.

Обзор
=====

Рабочие процессы описаны ниже.

### Создание задачи

Пользователь указывает название и описание задачи. Система должна сохранить задачу в бэклоге.

Поддерживаются поля:
* название
* исполнитель
* срок

## Отчёты

Отчёт по скорости строится за последние шесть спринтов.
